# M3-1 地图浏览器重构 · 分派规格（P1，下一会话的第一个任务）

> 2026-09-26 用户裁定。目标：把"复杂、看不懂"的地图页面改成普通人一眼能懂的地图浏览器。
> **先别碰**：.map 地形、shader、光照、动画、特效、碰撞、寻路。

## 验收（6 条，全过才算完）

1. 点「地图」能进入。
2. 能看到中文白话别名（有证据标注的才显示）。
3. **原始地图 ID 永远保留**——显示成两行：`大理城` + `w1351_ll_dl_002`，绝不替换原名。
4. 选中 `w1351_ll_dl_002` 能进入地图。
5. 真正看到大理的灰模物件（像素级证据，沿用 readPixels 取证法）。
6. 右侧白话面板：名称/ID、格子 103、实例 6119、成功定位 6101、无法定位 18、地形未解析、贴图部分可恢复、碰撞未解析、寻路未解析——**只显示事实，不猜**。

## 三栏布局

- **左**：地图列表。有证据别名显示「大理城」，没有的显示「未命名地图」；**原 ID 永远在下面一行**。
- **中**：3D 视口。旋转/缩放/平移/俯视/斜视/单击物件（单击→高亮 + 右侧联动显示该实例的名字、来源文件、行号——`58e2931` 已带「哪个文件第几条」）。
- **右**：这张地图的事实面板（验收第 6 条的字段）+ 单击物件的详情。

## 中文别名口径（红线修订，2026-09-26）

- **原始名称永远保留**：别名只是"加一行"，不是"替换"。
- 别名必须来自**人工标注或证据**（游戏内名称表、官方资料、用户确认）；**没有证据就显示「未命名地图」**。
- 别名数据：`.scratch/map_aliases.json`（格式见该文件；当前种子只有 1 条：`w1351_ll_dl_002 → 大理城`，来源=用户人工标注 2026-09-26）。**不许按拼音猜新别名。**
- 展示层加中文，数据层键仍用原 ID（红线 4 不变）。
