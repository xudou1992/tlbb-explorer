## 2. uvfit 判别器（已落地，`crates/core/src/bin/uvfit.rs`）

原理：把网格 UV 三角形栅格化成 256² 覆盖罩 → 候选贴图降采样 → 算**岛内/岛外亮度方差比**
（真被画过的贴图：岛内是绘画细节、岛外是溢色垫底；错贴图的岛外往往还是别人的画）。

实测（西域窃贼衣服 mesh × 1,650 池）：**10.1s 评完**，Top8 全部 512²·BC3·mips10。
目检（人工看合成图，评审 agent 通道不可用按纪律自己看）：

- rank03–06：深色布纹、褶皱、刺绣纹样落在岛内 —— **像窃贼深衣的 diffuse**；
- rank01/02：黑底稀疏白点 —— 像遮罩/细节图，指标被"黑底低方差"抬高了，是**已知偏差**；
- 结论：指标有效但不足以单独定案（本来就是 🟡），**定案 = ④3D 试贴 + 人工确认**。

合成图在 `.scratch/uvfit_out/`（rankNN_scoreXX_hash.png，红线=UV 岛边），全量 JSON
`uvfit_result.json`。

## 3. 修正后的实施顺序（把 ④ 提前）
