天龙八部·归来 —— 「客户端地图 → 浏览器 3D」可行性普查
只读作业；脚本 agent_map_*.py / 结果 .txt 同目录。样本：270 张图、10,228 个 .scene 实例表（753 型 9,288 + 749 型 940）、281,840 条实例。

【结论 A：现在就能做"浏览器里转着看的一张地图"，但只能是白模】
1) .scene 就是实例表，已解穿：u32 count | u32 753 | u32 0 | count × 761B；
   每条 = f32[16] 行主仿射矩阵（第4行=平移，第4列恒 0,0,0,1）+ char 名[697]。
   全库 281,840 条，255,013 条（90.48%）一路 join 到真实几何。
2) 位置是 f32 世界坐标（非 f64），Y-up，地图 320×320 单位、格 32 单位。
   第二证据：floor(x/32)==文件名第2下标 且 floor(z/32)==第3下标，18,192/18,193 = 99.995% 吻合。
3) 指针污染不致命：.scene 里 0x7f.. u64 密度 11.5 条/KB（8.77 条/记录），但 100% 落在记录
   64..320 字节（名字 NUL 之后的引擎侧挂区）；矩阵 0..63 在 18,812 条里只命中 1 次 → 能救。
   .map 更干净：21.5MB 里 4 字节对齐指针仅 42 个（0.002/KB），全在 152B 头，1.66MB 主体 0 个
   → 旧结论(1)"烤进指针所以不可移植"推翻。

【两个卡点（决定只能到白模）】
4) 贴图整条线全断：地图线 .tga 引用 10,512 条（mtl 6,379 + scene 2,064 + sfl 2,069）→ 实体 0 条
   （0.00%）；全库 .tga 解析率 25/30,585=0.08%；有名 2,259 张全在 ui/。lightmap 这一类根本不存在
   （path 含 lightmap 0 条，无 .lmt）。
5) 地形高度图没找到：.map = u32 1|A|B|152 + A×B 个 4160B 块；块内是 4 字节单元 (0,b1,b2,0)，
   b1 只有 4~18 个不同值、b2 只有 2~11 个；cs_001 的 41.6 万格只有 13 种组合（(5,8) 52.6%、(0,0) 44.5%），
   全文件搜不到连续 f32 高度串 → 它是地形编码格（层/斜度/可行走），不是高度图。
   1,713 个被引用名里只有 5 个像地面片。高度只能从 25 万个物件脚印 y 反推 → 假设，未证实。

【修正旧结论】
(2a) mapref = u32 count, u32 280：成立。887 个全 288B=8+280，u32[0]∈{4,5}，体内纯指针、无名字，不需要。
(2b) 场景网格表 = u32 count, u32 753：半对。753 是"每记录字节数−8"，真实步长 761、头 12B
     （size = 12+761·N−8，尾 8B 被压掉）；另有 940 个文件用 749（步长 757）。

【新事实：9% 缺口可修，不是数据缺失】
ResourcePath.cfg 实测约 72,760 条全路径（前缀出现 73,501 次），含 .mesh 名 22,172、.tga 名 20,315；
resources.db 只落 57,274 条（.mesh 有名 7,996、.tga 有名 2,191）。场景引用的 4,456 个 .mesh 名里
4,414（99.1%）在 cfg 有名有路径，仅 3,251 进了 db → 1,163 个名 / 22,700 条实例（8.05%）是
"cfg 有名、db 丢了"；连 cfg 都没有的只有 42 名 / 52 条（0.02%）。
（推断）补全 cfg/JRPC 解析（现为 names_jrpc.tsv 57,274 行）并把 12,676 个无名 geom/raw（1.39GB）
重新挂上路径，可把覆盖率 90.5% → ~99%。项目记忆"贴图无名是常态"要限定：名字在 cfg 里，
缺的是 名字→实体 的链接。

【最小第一步（2~4 人日）】选 w1351_ll_dl_002（大理，实测 99.8% 可渲染）：
a. 103 个 .scene → 60 行解析函数出 6,112 条实例（0.5 日）；
b. 按名 join mobile_maps_source/*.mesh → 复用现有 glb 链：209 个唯一模型 / 去重 88k 三角形，
   实例化 1.47M 三角形，three.js instanced mesh 毫无压力（0.5 日）；
c. 地面先给平坦底板+网格线，不承诺地形（1 小时）；d. 相机按 320 见方、物件高 ~10 单位量级（0.5 日）；
e. 2D 俯视清单页白送（0.5 日）。不要做：贴图上色、真实地形、lightmap。
