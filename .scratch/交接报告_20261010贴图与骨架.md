## 3. 贴图线为什么「测不了召回」——六条桥已证伪，别重走

`score = insideVar/(outsideVar+4)`，候选池 SQL 写死
`type='texture' and path is null and width>=512 and codec in ('RGBA32','BC3') and mips>=4`
（`crates/core/src/preview/uvfit.rs:190`）→ 池 1,650 张全出自 24,261 张**匿名**贴图。
带名字的贴图只有 2,271 张、全是 ≤60px WEBP 图标，**一张 ≥512 都没有**。两个世界：
hash 交集 0、filecrc 交集 0、匿名贴图在 relations/refs/amembers/assets 里**零入边**、
mtl 点名的 30,599 条 `.tga` ref 只有 25 条解出 hash、`path_hash` 拼路径 1,500 种写法 0 命中
（函数本身对 4,000 行有路径的全对）、400 份 mtl/mdl/mesh 共 14.9 MB 按 8 种对齐扫 hash 0 命中。
完整数字与脚本：`.scratch/tex_归属证据缺失_20261010.md`（`tex_recall.py`、
`tex_answer_probe.py`、`tex_pathhash_bridge.py`、`tex_pathspell_probe.py`、`tex_bytescan_hash.py`）。

**推论**：任何「自动算正确率 / 自动校准阈值」的提议先按此否定。要真答案只有两条路：
人工确认（覆盖表 `model_texture_override.json`，机制已上：`0d8107e` 加载即贴），
或**运行时挂钩**看引擎给某个模型实际绑定哪张贴图身份。后者要起客户端——**先问用户**。
