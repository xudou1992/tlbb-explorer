## 5. 环境与操作纪律（新增坑全在这，旧坑见上一份交接 §6）

- **CDP 验收工具链**（`.scratch/verify_playback/verify2.mjs` 是模板）：
  - 本机有 clash 系代理，**curl/node 访问 127.0.0.1:9222 必须绕代理**
    （curl 加 `--noproxy "*"`；node 设 NO_PROXY）。
  - 启动带 CDP 的 app：`WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS` 环境变量
    **必须**用 `ProcessStartInfo`（`UseShellExecute=false` + 显式
    EnvironmentVariables）传，Start-Process 传不进去。
  - 截图走 CDP `Page.captureScreenshot`（PrintWindow 全黑）；要先
    `Page.enable` + `Emulation.setDeviceMetricsOverride(1500x950)`；
    clip 截图对隐藏元素报 "0 width"，回落全视口。
  - **顶栏导航**：`#tabAssets`（资产视图）/#tabBrowse（数据包浏览）。
    `.row-item` 是全文档选择器——**不先切到资产视图，click 会打在隐藏 DOM
    上**，DOM 断言全绿但 rects 全 0、画布 1x1（这次栽过）。
  - 用户在电脑前：弹出的 app 窗口可能被用户关掉（本班发生过两次），
    CDP 突然 ECONNREFUSED 先查进程再怀疑代码。
  - 断言要验「可见状态」而非 DOM 存在；确认/撤销后界面有异步重刷，
    立刻读状态会读到旧帧。
- **CRLF 陷阱（新）**：python `open().read()` 通用换行模式会把 CRLF 吃成
  LF，写回后整个文件行尾翻转（0d8107e 里 lib.rs/texture_override.rs/api.js
  中招，内容正确但 blame 全指向这笔）。**改 CRLF 文件用 Edit 工具**，或
  python 二进制读写（`open('rb')`/`open('wb')`）。
- 构建三件套不变：`CARGO_TARGET_DIR=D:/TLGL/.scratch/rc3` + `--jobs 1` +
  `--offline`；改 web/ 必须 `node app/web/build.mjs` 再重建 exe 才生效；
  链接 os error 5 = exe 被运行中的 app 锁着，先杀实例。
- 前端测试 `cd app && npm test`（298 条）；地图金标准 `node tools/map_golden.mjs`
  动过 scene/几何解析才跑。
