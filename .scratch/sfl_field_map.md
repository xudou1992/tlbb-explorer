日期：2026-09-24。全程只读；本报告所有数字都注明分母口径（"全库 297"＝`out/tree/mobile_maps/*/*.sfl` 全量，"抽样 12"＝固定随机种子 20260924 从 fb/ll/gj 各抽 4）。

## 一句话结论

`.sfl` 是**单张地图的天空/雾/云环境配置文件**：JBCF 容器（magic `4a434246`、版本 8、root chunk id 86）内只有 3 个兄弟块（记录区 77、静态参数区 76、云层列表 40），外加一张字符串表，字符串表里**明文写着属性名和按"一天时刻"打点的动画曲线**（Ambient color / Fog one density / Sky top color / Moon0-30 Alpha / Sun Angle 等 21 个属性 + 60 个 `.tga` 贴图名）。它的字节布局在 297/297 上精确闭合，但**不含任何格子坐标、条目数或偏移表**——与"地图索引"无关，与前轮"不是索引"的结论一致。

## 1. 容器内部文法（297/297 全量验证）

与 `tlbb-explorer/crates/core/src/jbcf/parser.rs` 同一套外层文法（`[0]'JBCF' [4]0 [8]8 [12]bodyLen=size-16 [16]root: id=86, size_words@20`，字符串表块 id 85 在 `round8(size_words)+24`）。root 数据区 `[24, strtab)` 的内部布局：

```text
@24   chunk77 头  [77, 0, 0, z77, L77]     z77=3（289 图）或 2（8 图，见 §4.4）
@44   子头        [39, n, W, 0, 0]         n=记录数, W=记录区字长（8×… 太小；实际单位是 u32 字）
@64   n 条记录，恰好铺满 W 个字            ← 全库 297/297 精确闭合（sfl_fields.py ok77）
@64+4W chunk76 头 [76, 0, 0, 4, L76]
      子头        [4, 1, 2, 0, 0]（297/297 恒定）
      记录流（贪心铺到第一个非法 key 为止）
      子块链      [6,0,0,0,0] + [8,0,0,z8,L8=36·z8]（297/297 都是这一对，sfl_fields kids76）
        chunk8 = z8 行 × 36 字：每行 = 子头 [9,14,31,0,0] + 31 字 14 条记录
                 1529 行全部精确铺满（sfl_fields_out.txt 'rows8 exact'）
@…    chunk40 头  [40, 0, 0, z40, L40=14·z40]（283 图 L40%14=0；2 图 z40=22 时 L40=28/行）
      子头        [41, 1, 2, 1, 7]（281 图；2 图为 [41,1,2,3,21]；14 图无 chunk40）
      记录流      (4,158)/(4,175) 6 字记录成对出现，铺满（283/283，recs40 full tile）
@strtab           字符串表块 id 85：[u32 id][size][flag=0][count][(len,hash)×count][字符区]
```

记录文法：`[u32 key=(cls<<16)|fld][pw 个 u32 载荷]`。载荷宽度：

| cls | 宽度(u32) | 观测载荷 | 解读 |
|---|---|---|---|
| 0 | 1 | 恒 0 | 整数 0 占位（仅 chunk8 行内出现，fld=33） |
| 1 | 1 | int 1 | 布尔/开关 |
| 2 | 1 | int（250、0） | 整数标量（fld 174/183） |
| 3 | 1 | f32 | 浮点标量 |
| 4 | **fld 相关**：fld 5=6 字、38/57/63/64=1 字、158/175=6 字 | int 数组 | 复合/记录型（含义未定） |
| 6 | 3 | f32×3 | 单位向量或 RGB |
| 7 | 4 | f32×3 + 0/1 | RGBA 色（第 4 量恒 0 或 1，全库无第三种值） |
| 8 | 4 | f32×4 | 参数三元组 + 0（如 (35,500,500,0)） |
| 10 | 2 | (1.0, 0) | 仅 mqts 两图（fld 72） |

字段号 fld 是**按 chunk 分命名空间**的：chunk77 与 chunk76 各自有 3/28、7/34、7/21 等号段，值域也各自统计（证据：chunk77 里 `(3,168)=1.2` 与 chunk76 里 `(3,28)=0` 同 cls 不同语义槽；chunk8 行内 `(3,11)=500` 与 chunk76 的 `(3,28)=0` 互不冲突）。

## 3. Q2（字符串表）：有，内容如上

这是本次最有价值的发现：**`.sfl` 自带 schema 明文**。字符串表不是依赖清单的孤岛——它是同一份天空配置的可读转储，二进制记录是同一配置的机器侧编码。两边的对应关系用数值逐一撞出来（§2.1 加粗项）：文本曲线的首帧/常数帧 = 二进制当前值。**注意**：文本侧列出的 31 条 `MoonN Alpha`、3 条 `SphereGroupN Alpha` 曲线在二进制侧**找不到对应记录**（chunk77/76 最大 fld 173、无 Moon 槽位）——月亮动画参数要么在引擎里写死，要么在别的资源里，未定。
