## 2) 模型（行向量约定，沿用 wave20 口径）

每根骨 j 一个带符号坐标置换轴 `A_j`，轴按**分组**给定、沿整棵子树传播（组内共用一个 A）：

```text
A_parent(树根) := A_j                       // 树根无父骨，父轴取自身
A_parent(j)    := A_{group(parent j)}       // 组界处 A_parent ≠ A_j
P_j(t)          = (anchor⁻¹ · world_t)_j    // = pose::skin_palette(h, frame0_worlds, world_t)，与轴无关
D_j(t)          = A_parent⁻¹ · P_j(t) · A_j // 播放实际用的调色板
轴是带符号置换 ⇒ A⁻¹ = Aᵀ（无平移分量，转置即逆）
```

`P_j(t)` 预计算一次（与候选无关），每个候选只做共轭 + `posed_vertices` + `edge_stretch`。

### ⚠ 档案级警示：**frame0 恒等不能当判据**

全身同一个 A 时 `P_j(0) = I ⇒ D_j(0) = A⁻¹·I·A = I`，**对任何轴选择都成立**。
所以「第 0 帧回到 bind 姿态」是一个恒真的式子，**不能区分谁好谁坏**；以后谁拿 frame0 恒等
当证据，那是在拿恒真式当证据。**只有撕边数能判。**

分组还有一个副作用要说清：组界骨 `D_j(0) = A_parent⁻¹·A_j ≠ I`，第 0 帧**不再**是 bind 姿态，
理论上会给撕边数掺进一个静态偏移。本班因此同时报「合计（含第 0 帧）」「剔 0 帧」「第 0 帧单独」三套数。
**实测这个偏移落不到皮肤上**：全部前列候选的 `第0帧 over15 = 0`、`max = 1.00`，剔 0 帧与合计两套数一模一样。
原因是本样本的组根里 `bip01_l_clavicle`、`bip01_l_thigh`、`bip01_r_thigh`、`bip01_neck` **都没有权重表**
（见 §5「带表 26 根 / 无表 20 根」），唯一带权的组根 `bip01_r_clavicle`（5 个顶点）在最优候选里恰好拿到
与脊柱相同的轴。**这条要说反了也不许含糊：判定用的 14/16/13 帧里没有一帧是靠组界静态偏移刷分的。**

## 8) 残差落在哪：轴修不动的那一部分

`axis_probe_full.txt` §7 把 over15 最多的那一帧的撕边按**两端主贡献骨**（权重最大的骨）归堆，
并单独统计「两端是同一根骨」的份额：

| 动作 | 候选 | 该帧 over15 | 同骨内部 | 份额 |
|---|---|---:|---:|---:|
| idle01 | 恒等（第 24 帧） | 379 | 98 | 26% |
| idle01 | 主候选（第 24 帧） | 139 | 24 | 17% |
| walk | 主候选（第 8 帧） | 166 | 72 | **43%** |
| run | 主候选（第 6 帧） | 322 | 138 | **43%** |

**同骨内部的边 = 两端都归同一根骨**。一根骨的调色板是仿射相似变换，正交轴共轭（`A⁻¹·P·A`）**不会
改变它的拉伸量**——所以这 17–43% 是轴这条路**天生碰不到**的残差。它们只能来自：
`.ani` 轨道里的 `scales` 通道（`pose::trs_matrix` 把 scale 直接乘进旋转 3×3），或
`unify_weights` 的补根/归一（`WeightCase::RootFilled`/`Rescaled`：根骨 `000` 的调色板恒等、不跟随变形，
补到根骨的那份权重把同一片皮肤往两个方向拽）。§7 里最刺眼的几条正是这种形状：
`bip01_l_toe0 ↔ bip01_l_toe0` 26–36 条 / 10–13×、`bone01 ↔ bone01` 26–34 条、
`bone10_mirror02_mirror01 ↔ 自己` 64 条 / 7.83×、`bone05 ↔ bone05` 34 条 / 6.30×。

剩下的跨骨对也集中在 `000 ↔ X`（补根）与 `bone05 / 镜像链 / upperarm`，**不是某一条组界接缝**，
所以「再多分几组、给每肢一根更细的轴」没有靶子可打。
